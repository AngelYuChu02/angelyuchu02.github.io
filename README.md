# Yu Chu Personal Website

This is the current static version of Yu Chu's personal website for GitHub Pages.

Only this website repository is intended to be public. Project source code, course repositories, research notes, and other working repositories can remain private.

## Local Preview

From this folder:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173/en/
```

## Deploy With GitHub Pages

This site is already built. Commit and push the static files to the `main` branch of:

```text
AngelYuChu02/angelyuchu02.github.io
```

GitHub Pages will publish the site from the public repository at:

```text
https://angelyuchu02.github.io
```

If a custom domain is added later, update sitemap/canonical metadata from root-relative paths to the final absolute domain for cleaner SEO.
